# Week 9 - House Price Prediction

## Project
A beginner-friendly Machine Learning project to predict house prices using Python and scikit-learn.

## Current project status
This package contains the complete project structure, notebook code, documentation templates, requirements, and the supplied dataset.

**Important:** The notebook has NOT been executed on the dataset yet. Therefore, actual model metrics, plots, conclusions, and screenshots are intentionally left for the analysis stage.

## Files
- `house_price_prediction.ipynb` - complete working notebook with data preparation, models, evaluation, visualization, and interpretation code.
- `house_prices.csv` - supplied dataset.
- `model_evaluation_report.md` - report template with sections for methodology, metrics, results, and insights.
- `requirements.txt` - Python dependencies.
- `SCREENSHOTS_REQUIRED.md` - exact screenshots still needed for submission.
- `outputs/` - reserved for generated prediction/evaluation outputs after running the notebook.
- `screenshots/` - reserved for screenshots of the working project.

## Setup
```bash
python -m venv venv
```

Windows:
```bash
venv\Scripts\activate
```

Install dependencies:
```bash
pip install -r requirements.txt
```

Start Jupyter:
```bash
jupyter notebook
```

Open `house_price_prediction.ipynb` and run the cells in order.
